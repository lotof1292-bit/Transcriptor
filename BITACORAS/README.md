# Bitácoras

Estas bitácoras son acumulativas. No se reemplazan entradas antiguas: se agrega una entrada nueva por cada modificación.

- `APP-WINDOWS.md`: aplicación de escritorio Python/PyInstaller.
- `APK-GENERAL.md`: cliente Android, servidor y funciones compartidas.
- `APK-FREE.md`: permisos, límites y funciones específicas de Free.
- `APK-PREMIUM.md`: procesamiento conectado, BYOK, servidor y funciones Premium.

La actualización de estas bitácoras y de `ESTADO-Y-FALTANTES.md` forma parte de la definición de terminado de cualquier cambio.
